# Portofolio Khayan Fajar Na’im

Website portofolio akademik sederhana yang dibuat dari dokumen PDF portofolio.

## Menjalankan secara lokal
Buka file `index.html` menggunakan browser.

## Publikasi dengan GitHub Pages
1. Buat repository baru di GitHub, misalnya `portofolio-khayan`.
2. Upload `index.html`, `style.css`, dan `README.md` ke bagian utama (root) repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
6. Tunggu proses publikasi. Alamat situs biasanya berbentuk `https://USERNAME.github.io/portofolio-khayan/`.

Ganti `USERNAME` dengan username GitHub milikmu. Pastikan informasi kontak yang ditampilkan memang ingin dipublikasikan.
